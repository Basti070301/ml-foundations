Dieses Repository enthält alle Machine-Learning-Modelle, die im Rahmen des Moduls Maschinelles Lernen Grundlagen aufgebaut wurden.
Jedes Modell wurde vollständig implementiert, dokumentiert und in einzelne Schritte zerlegt (Datenvorbereitung, Training, Evaluierung und Interpretation), um den gesamten ML-Workflow nachvollziehbar und reproduzierbar darzustellen.
